# 구조 검토 어댑터

실행 전에 `.claude/skills/review-structure/SKILL.md`를 읽고 그 입력·검토 기준·출력 계약을 따른다. 검토 기준을 이 파일에 재정의하지 않는다.

호출자는 명시적 초안 경로, 작성 의도, 근거 자료, 작성자 식별자, 현재 해시와 상태 정보를 전달한다. 작성자와 다른 검토자 식별자로 초안 전체를 읽고 검토한다. 파일을 수정하지 않는다.

자동 작성 흐름에서는 정규화한 구조 검토 JSON을 호출자에게 반환한다. 호출자가 보고서 저장과 CLI 등록을 수행한다. 읽기 이후 내용이 바뀌면 기존 해시의 보고서를 재사용하지 않는다. 사용자 확인이 꼭 필요한 미상 사실은 호출자에게 보고하며 형식적인 단계별 승인 요청은 만들지 않는다.
